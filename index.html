MailFlow - Asistente de voz inteligente para correo electrónico

Flutter Java Spring Boot Gmail API OAuth2 PostgreSQL Docker Text-to-Speech

💡Descripción: Aplicación multiplataforma diseñada para convertir los emails entrantes en audio, mejorando así la accesibilidad y la productividad. La app integra la API de Gmail, la conversión de texto a voz y, en el futuro, la función de resumen con IA para que los usuarios puedan leer sus correos electrónicos sin usar las manos. Desarrollada con Flutter para dispositivos móviles y de escritorio, y con Spring Boot para los servicios de backend.

🎯 Funcionalidades planificadas y hoja de ruta:

  • Leer emails en voz alta
  • Priorización inteligente
  • Resúmenes de IA
  • Respuestas de voz
  • Categorización de emails
